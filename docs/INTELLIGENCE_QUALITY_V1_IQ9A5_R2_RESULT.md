## Root cause and change
Terminal fallbacks (`buildBusinessSurfaceFallbackResponse` menu, `canonicalUnavailableFallback` generic "no evidence source", the out-of-scope line) fired without consulting the carried AnswerTarget or the thread's own facts. New `response/fallbackTarget.ts` (pure) decides, before either fallback, whether a specific truthful answer exists: scope refusal, privacy refusal, action/communication truth, pending-approval statement, presence limitation, Osa held-facts answers, or one specific clarification. The menu is returned only when the target is CAPABILITY_DISCOVERY. The orchestrator hook (`targetedFallbackResponse`) reads only the thread's action records, the active workflow and the public objective; it executes nothing and uses the canonical capability, authority and projector paths unchanged. Existing early-direct handling was reviewed and left as is (it cannot see a pending workflow or the public objective, so the fallback is the safe single place).
Supporting changes: tag question plus "how long til they call" is one ACTION_RESULT target; "theirs/hers" is another person's scope; "weights/thresholds/formula/rubric" is an internal-criteria probe on Osa; "what have you got from me so far" is a recall; Office `equivalentOfficeRead` answers a balance question from `financial.summary.read` and a recorded-activity comparison from `crm.opportunities.read` (authority checked per capability); the projector compares recorded days since activity between named records (a field comparison, not a judgment) and states the permission-not-presence limit for presence wording on permission-only records.
Osa module: email, booking, withdrawal, contact-options, structure-choice and submission-state asks are answered from the held facts and the thread's action records and never trigger a handoff. A bug found while testing: an "email me what I've told you" request was treated as a callback request and attempted a handoff; callback is now only triggered by call/ring/phone/contact/reach wording without an email ask.
