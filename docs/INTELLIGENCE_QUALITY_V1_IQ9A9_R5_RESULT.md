# IQ-9A9 R5 — routing precision and subject resolution: result

Start HEAD `db949bf4324adcf934237f6a8b902e27fa5a0eb6` (= origin, clean). Phase 0 adjudication of R4 item 155 and the frozen routing baseline were committed first (`92d53fa`, `docs/INTELLIGENCE_QUALITY_V1_IQ9A9_R5_BASELINE.md`). IQ-9A is not certified; no merge, deploy, R6 or IQ-9B.

## Changes (existing frame, concept bridge, registry, target resolver and authority contracts; no new router)
- **Short device names.** `namedDevicePhraseFromControlMessage` now extracts the named device by removing control and politeness words (not only a leading verb) and accepts names of two characters; `scoreDeviceCandidate` matches a name of three characters or fewer as a whole word against the device's own name or alias, never as a substring ("ac" is not a hit in "Back Door Lock"). Resolution is still against the actor's authorised home registry: two devices with the same name are `ambiguous` (the user is asked), an unknown name is `not_found`, and with no home in scope nothing is looked up. "Shut the AC down" and the additive "Kitchen light off too" are power commands.
- **Named subject plus pronoun.** "The Bedroom Light looks stuck, turn it off" binds "it" to the subject named earlier in the same turn; a bare "turn it off" names nothing and is never bound to an earlier list or object.
- **Surface-aware finance.** On Office, "portfolio financial position / balance / revenue / cash" resolves to the financial domain (`financial.summary.read`) while "portfolio entries" stays the entries list; a resident's "balance" stays the wallet and estate-wide wording is refused (never answered from the wallet); Facility and Osa remain refused.
- **Read versus action.** A past-tense question about an action asked while a device proposal is pending ("Did you switch off the AC?") is answered from the thread's action records and the pending state ("No — nothing has been sent or changed… waiting for your approval") instead of being consumed as clarification input or starting a command; a state question about the pending device ("so the AC is definitely off, yeah?") adds that its latest reading is not current. State questions ("Is the AC on?") never create proposals. Execution authority is not widened.
- **Osa.** "Where is it?" with held facts answers the location.
